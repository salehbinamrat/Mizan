# تغيير كلمة مرور مسؤول البرنامج والموظفين

- ينشأ مسؤول البرنامج الأول عبر معالج التهيئة الأولى، دون أي حساب افتراضي.
- بعد الدخول الأول يمكنه إنشاء الأقسام والمستخدمين، وتحديد الأدوار والصلاحيات ونطاق القسم وحد المستخدمين.
- تبقى إدارة حسابات الآخرين محجوزة للمسؤول الأول؛ لا يسمح لاسم الدور "Admin" وحده بالتصعيد.
- يستطيع أي مستخدم **مسجل الدخول** تغيير كلمة مرور حسابه من تبويب «حسابي». يلزم إدخال كلمة المرور الحالية واختيار كلمة جديدة قوية وتأكيدها.
- بعد تغيير كلمة المرور تنتهي جميع جلسات ذلك الحساب، ويتطلب النظام تسجيل الدخول مجددا. تُسجل العملية في سجل التدقيق دون تخزين نص كلمات المرور.
- لا يستطيع المدير تغيير كلمة مرور المسؤول الأول من شاشة الموظفين. فقدان حساب المالك يتطلب إجراء استعادة منفصلا محميا، وليس إعادة تهيئة تلقائية.

# ميزان الطبي — نظام التصميم المركزي V1

تصميم عربي RTL موحد دون تغيير صلاحيات القسم أو الصناديق أو PostgreSQL.

## الهوية

- Midnight Navy #16394B للنصوص والشريط الرئيسي.
- Medical Teal #087D88 للأزرار الأساسية والتبويب النشط.
- Cool Silver #F3F6F9 للخلفيات، وWhite #FFFFFF للمحتوى.
- MedicalLine #D7E3EA للحدود.
- الأخضر #18765A للنجاح، والبرتقالي #A86422 للتحذير، والأحمر #B64559 للخطر.

## التصميم

- حواف الأزرار والإدخال 9px، البطاقات 13–16px.
- رأس جدول بارتفاع 43px، صف 38px، وتظليل متناوب.
- لوحة مالية بأربع بطاقات متساوية في صف واحد.
- جميع الموارد في Themes/MedicalTheme.xaml وتُحمّل مرة واحدة من App.xaml.
- مفاتيح التركيز مرئية وRTL محفوظ، مع بقاء الأرقام والحقول التقنية LTR.

## اختبار القبول

- يجب اجتياز xUnit واختبارات WPF وPostgreSQL.
- يجب نجاح Windows Core وWindows Release قبل إنتاج x86/x64 Portable/Installer.
- يجب اختبار التكبير 100/125/150% على Windows يدويا، وحقول المرور، والقوائم والطباعة.
- لم تكتمل بعد أداة الاستعادة الآمنة للنسخ المشفرة إلى قاعدة بيانات الإنتاج.

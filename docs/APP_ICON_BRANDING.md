# هوية أيقونة ميزان الطبي

الرمز: **M** فضية تجمع الميزان المالي والصليب الطبي وتخطيط القلب داخل مربع كحلي مستدير محاط بقوس فيروزي.

## مواصفات

- **Windows ICO:** صورة متعددة الدقة: 16 و24 و32 و48 و64 و128 و256 بكسل.
- **WPF resource:** `Assets/MizanMedical-UI.png` للشاشة الرئيسية، وتسجيل الدخول، ومعالج إنشاء المسؤول الأول.
- **التطبيق:** `ApplicationIcon` يضم الأيقونة إلى `MizanMedical.Desktop.exe` بما في ذلك Portable.
- **التثبيت:** `SetupIconFile` يضيف الشعار إلى ملف Inno Setup؛ واختصارات Start Menu وDesktop تستخدم أيقونة EXE ذاتها.
- **اختبارات:** `ApplicationIconContractTests` وWindows Core وWindows Release، قبل بناء x86/x64 Portable وInstaller.

## ملاحظات

- تم تصميم الرمز بصورة أصلية لبرنامج ميزان الطبي، ولا يحاكي علامة تجارية منشورة.
- لا تتغير صلاحيات المستخدمين أو مسارات API أو بيانات المستشفى بهذا التعديل.
- استخدام صورة PNG داخل الواجهة محلي ولا يحتاج إلى الإنترنت.
- يجب فحص ظهور الأيقونة عند أحجام 100% و125% و150% داخل Windows فعليا بعد التثبيت.

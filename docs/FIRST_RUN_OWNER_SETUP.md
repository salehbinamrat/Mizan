# التهيئة الآمنة لمسؤول ميزان الطبي لأول مرة

**الحالة:** ميزة تهيئة أولية تجريبية؛ لا تعتبر بديلا عن ترحيلات PostgreSQL والتحقق الأمني قبل النشر الفعلي.

## كيفية الاستخدام

1. جهز خادم ASP.NET Core وPostgreSQL من مصدر موثوق، مع تثبيت شهادة HTTPS عند استخدام الشبكة الداخلية.
2. إذا كانت قاعدة المستشفى جديدة تماما ولم تضم أي مستخدم، شغّل خادم API يدويا في نافذة **Console محلية غير معاد توجيه مخرجاتها**. لا تضبط `MIZAN_BOOTSTRAP_USERNAME` و`MIZAN_BOOTSTRAP_PASSWORD` في هذا المسار.
3. يعرض الخادم **رمز تهيئة مؤقتا وعشوائيا**. لا تشاركه في المحادثات أو البريد أو سجل GitHub.
4. شغّل نسخة Windows الخاصة بميزان الطبي على **نفس الخادم**، مع `serverUrl` يشير إلى `https://localhost:5081` وشهادة محلية موثوقة.
5. تظهر «تهيئة حساب مسؤول البرنامج لأول مرة» بعد فحص حالة الخادم. أدخل الرمز و**اسم المستشفى** والاسم الكامل للمسؤول واسم الدخول وكلمة مرور قوية ثم أكدها.
6. بعد الحفظ يلغى الرمز في ذاكرة الخادم، وتعود شاشة تسجيل الدخول الموحدة. سجل الدخول باستخدام **اسم المستخدم واسم المستشفى وكلمة المرور**. الاسم مرتبط بهذا الخادم وليس خيارا للحصول على صلاحيات أوسع.
7. من إدارة المستخدمين أضف الأقسام وحدود عدد الموظفين، ثم موظفي كل قسم وصناديقهم الشخصية وصلاحياتهم.

## قواعد أمان صريحة

- لا يوجد اسم مستخدم أو كلمة مرور مدير افتراضيان.
- لا يسمح بطلب التهيئة من أجهزة المستخدمين عبر LAN؛ قبول `POST /api/initial-setup/complete` مقيد بعنوان loopback على الخادم وبالرمز الصحيح.
- يلزم خادم تفاعلي لعرض الرمز فقط؛ في خدمة Windows أو Docker غير التفاعلية يظل مسار التهيئة القديم عبر **متغيرات بيئة محلية على الخادم** متاحا، ولا يطبع أي رمز إلى سجلات الخدمة.
- إذا ضاعت صلاحية المدير في قاعدة لها مستخدمون، لا ينشئ النظام مديرا بديلا تلقائيا؛ يلزم استرداد إداري مراقب.
- لا تسجل كلمات المرور أو رمز التهيئة في السجلات والملفات. رموز الجلسات تُحفظ مجزأة.
- يستخدم الخادم معاملة `Serializable` لفحص عدم وجود مستخدمين وإنشاء المسؤول في عملية واحدة، لإحباط التهيئة المتزامنة.
- يعتمد العرض في Windows على صلاحيات الحساب المخزنة على الخادم، وليس على نص الدور في شاشة الدخول.

## الاختبارات

- `InitialOwnerSetupTests`: صحة بيانات المدير، قوة كلمة المرور، مطابقة الرمز، منع التهيئة في شبكة غير محلية أو قاعدة غير فارغة.
- اختبارات Windows Core وWindows Release متوازية؛ داخل Release الاختبارات تسبق حزم x86/x64 Portable وInstaller.
- اختبار PostgreSQL المستقل باقٍ ويجب أن ينجح، مع اختبار إعداد أول من جهاز الخادم لاحقا قبل النشر النهائي.

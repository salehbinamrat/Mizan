## التحسين الحالي على قواعد المالية
- اختبارات رفض القيود المتوازنة ظاهريا عند وجود أكثر من خانتين عشريتين.
- اختبارات رفض مبالغ القيود الأكبر من الحد المالي المعتمد.
- رفض دفعة إذا كان إجمالي الفاتورة أو المدفوع السابق خارج قواعد المال.
- الاعتماد على decimal والتحقق من المدين والدائن في كل سطر.

## بوابات الاعتماد
1. اختبار قواعد المالية والحدود وعدم تكرار إرسال المقبوضات.
2. تشغيل اختبارات API مع PostgreSQL عند وجود طلبات متزامنة.
3. مسارا Windows Core وWindows Release متوازيان.
4. في Windows Release، الاختبارات تسبق بناء x86/x64 Portable وInstaller.
5. لا يُدمج أي PR في main عند فشل أي اختبار أو بناء.

## إضافات ChatGPT
- GitHub: مثبت ومطلوب لرفع الفروع وطلبات الدمج وتتبع CI.
- Figma: مثبت لتصميم RTL وإعادة استخدام المكونات، دون نسخ الواجهات المحمية.
- Context7: مثبت لمراجعة توثيق الحزم ومكتبات .NET.
- Notion: موجود لوثائق القرارات عند موافقة المستخدم، وليس لتخزين الكود أو أسرار المستشفى.
- Microsoft Power BI: اختياري للتقارير الإدارية من بيانات مجمعة ومنزوعة الهوية؛ ليس ضروريا للتشغيل الأساسي.
- PostgreSQL لا يحتاج إضافة ChatGPT؛ يجب إبقاء قاعدة بيانات المستشفى على الشبكة الداخلية مع الحماية.

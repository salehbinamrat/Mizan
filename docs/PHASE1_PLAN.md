# ميزان الطبي — خطة تثبيت المرحلة الأولى

**الحالة في 2026-11-16:** مشروع Windows متعدد المستخدمين، قيد التطوير، غير معتمد للاستخدام المالي الفعلي.

## النواة

- ASP.NET Core API + PostgreSQL مركزي داخل شبكة المستشفى
- عميل Windows WPF بواجهة عربية RTL
- صلاحيات مستقلة للاستقبال والصندوق والمحاسبة والإدارة
- مرضى، خدمات، فواتير، تحصيل جزئي، مصروفات، مناوبات، قيود مزدوجة

## إصلاحات السلامة المحاسبية

- رفض قيود متوازنة ظاهريا لكنها تحوي مبالغ أكثر من خانتين عشريتين أو فوق الحد المالي المسموح
- التحقق من إجمالي الفاتورة والمدفوع سابقا قبل التحصيل
- منع تجاوز الرصيد أو إعادة اعتماد العملية عند تعارض معرف الطلب
- تسجيل قيد محاسبي متوازن وسجل تدقيق لكل عملية مالية

## بوابات الجودة الإلزامية

1. اختبارات C# / xUnit للحسابات وحالات الحدود
2. اختبار تكامل PostgreSQL، بما فيه العمليات المتزامنة وإعادة المحاولة
3. تشغيل Windows Core وWindows Release بالتوازي
4. بناء Portable وInstaller لكل x86 وx64 بعد نجاح اختبارات Release
5. عدم دمج التغييرات في main إذا فشلت أي بوابة

## مخاطر قبل الإنتاج

- يلزم EF Core migrations موثقة بدلا من EnsureCreated
- اختبارات صريحة لإلغاء الفواتير والمرتجعات وإقفال الفترة
- اختبارات إعادة تشغيل الخادم وانقطاع الشبكة واستعادة النسخة الاحتياطية
- مراجعة حماية بيانات المرضى، وإبقاء قاعدة البيانات داخل الشبكة المحلية
- لا توجد اختبارات Windows مؤكدة لهذه المرحلة حتى الآن

**ملاحظة:** بقية ملفات المصدر حاليا في حزمة ZIP المحلية؛ هذه الوثيقة لا تعني أن التطبيق كاملا مرفوع إلى المستودع.

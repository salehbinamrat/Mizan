# تنظيف جلسات الدخول المنتهية دون تعطيل العمل

كان الخادم يمنع استعمال الجلسات المنتهية، لكنه يبقي سجلاتها في جدول `LoginSessions` إلى أجل غير محدود، مما يزيد حجم الفهرس على الخادم عند كثرة الموظفين والأجهزة.

## الإصلاح
- خدمة خلفية `ExpiredSessionCleanupService` تبدأ بعد اكتمال فحص الخادم لقاعدة البيانات.
- كل ساعة تعالج **حدا أقصى 2000 جلسة منتهية** في دفعات حجمها 500، باستخدام فهرس `ExpiresAtUtc` الموجود مسبقا.
- تعمل على اتصال ونطاق خدمات منفصلين عن طلبات الدخول والفواتير والصناديق.
- تستبعد أي جلسة لم تنته صلاحيتها؛ لا تتغير الحسابات ولا كلمات المرور ولا صلاحيات الأقسام.
- عند تعذر الاتصال تسجل تحذيرا ثم تعاود في الدورة المقبلة؛ لا توقف الخدمة الأساسية.
- في حال تعدد خوادم API تكون العملية idempotent؛ الحذف يعيد التحقق من انتهاء الصلاحية قبل التنفيذ.

## التحقق
- اختبارات xUnit للتواريخ وحدود الدفعات وعدم التوسع في الصلاحيات.
- بناء API والاختبار الفعلي عند تشغيل PostgreSQL عبر GitHub Actions.
- قياسات حجم جدول الجلسات وأداء فهرس جلسات الدخول قبل/بعد التشغيل على قاعدة تجريبية مطلوبة لإثبات مقدار التحسن بالأرقام.

# ضمان اكتمال الصلاحيات المرتبطة بإجراء مالي

الهدف: منع حساب يملك صلاحية إجراء، لكن شاشة الإجراء لا تتيح له البيانات الأساسية اللازمة لإكماله.

- إصدار الفواتير يحتاج إلى عرض المرضى، الخدمات، والفواتير.
- إنشاء سند قبض يحتاج إلى عرض الفواتير والمناوبات المفتوحة.
- تسجيل المصروف أو إقفال المناوبة يحتاج إلى عرض المناوبات.
- فتح المناوبة يحتاج إلى عرض الصندوق والمناوبات.
- إنشاء مريض يحتاج إلى عرض المرضى؛ إدارة الخدمات تحتاج إلى عرض الخدمات.
- عرض كل الصناديق ضمن النطاق المصرح به يحتاج إلى حق عرض الصناديق.

**هذه الصلاحيات ليست صامتة.** عند اختيار إجراء من شاشة إدارة المستخدمين يظهر تأكيد يوضح صلاحيات القراءة المضافة، ولا يرسل الطلب حتى موافقة مسؤول البرنامج. الخادم يتحقق من التبعيات ويرفض الطلبات التي تحاول تجاوز الشاشة.

حسابات موجودة مسبقا ذات صلاحيات ناقصة **لا تتلقى صلاحيات إضافية تلقائيا**؛ يلزم أن يراجع مسؤول البرنامج حسابها ويعتمد القراءة المطلوبة. الصلاحية لا تتجاوز حدود القسم المحدد، ولا تتضمن حق إدارة المستخدمين أو الصناديق الأخرى.

لا يعد هذا دعما كاملا لاستقبال متعدد الأقسام أو إلغاء الفواتير؛ هذان مساران منفصلان يحتاجان هجرة بيانات واختبارات.
